# cursor-stock-monitor

A stock monitoring tool built for the Cursor AI editor environment.

## Overview

This project provides stock market monitoring capabilities, designed to work seamlessly within the Cursor development workflow.

## Features

- Real-time stock price monitoring
- Configurable watchlists
- Alert notifications

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Landing-On-Mars/cursor-stock-monitor.git

# Navigate to the project directory
cd cursor-stock-monitor
```
